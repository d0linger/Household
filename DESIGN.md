# Household interface

The visual authority is the supplied Household module-system artifact and the 50 reviewed prototypes. Preserve this established identity rather than starting a new visual direction.

Use a compact locally available sans-serif stack, readable 16px form inputs, tabular numbers, 10px control radius, and consistent 44px touch targets. No remote fonts are needed. Icons come from a locally bundled licensed set. Long-form recipe instructions may use the system serif stack.

## Navigation and layout

Mobile: compact header with search, notifications, and settings; bottom module navigation. Show all active modules up to five; with six or more, show four and a working More destination. Settings remains reachable when no module is enabled. Desktop: persistent sidebar and a bounded main content area. Data stays in rows; forms keep labels visible.

## Behavior

Prefer quick entry, inline actions, readable validation, and undo for reversible actions. Preserve focus after updates. Show explicit loading, empty, conflict, and offline states. Never label a simulation or unexecuted operation as completed production work.
